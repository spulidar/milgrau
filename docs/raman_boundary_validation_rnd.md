# Raman boundary-validation R&D contract

## Scope

This note defines the scientific contract for future Raman-assisted validation of the elastic KFS boundary assumption. It is **R&D-only**. Productive Level 2 remains schema v3 / method v4, with `aerosol_ref_fraction = 0` and no Raman correction.

The immediate goal is not to build a full Raman aerosol product. It is to determine whether independent Raman information can falsify or support the elastic assumption that a candidate reference region is sufficiently aerosol-free for the chosen boundary condition.

## Why Raman is relevant

The current P5.4 evidence shows that an elastic candidate can be flat, persistent, path-complete and high-SNR while the lower-column KFS solution still changes materially when the reference altitude is moved. Controlled truth tests reproduce the mechanism when residual aerosol exists at the boundary.

A nitrogen Raman return provides information that is not generated by the elastic boundary inversion itself. That makes it a plausible independent constraint, provided receiver semantics, overlap, spectral response and molecular physics are explicit.

## 387 nm / 355 nm vibrational-Raman path

For a nitrogen Raman return at wavelength `lambda_R` from a laser wavelength `lambda_0`, the range-corrected Raman signal can be written schematically as

`X_R(r) = C * N_N2(r) * sigma_R(T,r) * O_R(r) * exp[-integral(alpha(lambda_0)+alpha(lambda_R)) dr]`.

Above complete overlap, and after accounting for the molecular terms, the classical Raman extinction relation uses the range derivative of

`ln[N_N2(r) / (P_R(r) * r^2)]`.

For a vibrational Raman channel such as the published SPU 387-nm nitrogen companion of 355 nm, aerosol extinction at the laser wavelength requires an explicit wavelength-dependence relationship between aerosol extinction at the emitted and Raman wavelengths. A common formulation writes the denominator as

`1 + (lambda_0 / lambda_R)^A(r)`,

where `A` is an aerosol extinction Ångström exponent or declared wavelength-dependence model.

R&D requirements:

* nitrogen number-density profile on the same vertical grid;
* molecular extinction at both emitted and Raman wavelengths;
* Raman signal uncertainty and derivative/smoothing uncertainty;
* an explicit overlap-valid range or measured overlap correction;
* explicit Ångström/wavelength-dependence treatment and sensitivity;
* current 387-nm receiver spectral-response provenance.

Absolute multiplicative Raman calibration cancels from the logarithmic derivative if it is range-independent, but overlap and range-dependent spectral/receiver effects do **not** cancel.

## 530 nm / 532 nm rotational-Raman path

The SPU 530-nm channel is published as nitrogen rotational Raman associated with 532 nm. It must **not** be treated as a generic vibrational-Raman channel merely because its nominal wavelength is close to 532 nm.

Pure/rotational Raman effective cross section can depend on atmospheric temperature and on the filter transmission across the rotational spectrum. The retrieved extinction therefore contains a term associated with the altitude dependence of the effective rotational-Raman cross section. The active filter/passband is consequently part of the physics, not cosmetic metadata.

R&D requirements before quantitative 530-nm use:

* active MerionC filter/transmission curve or defensible effective spectral response;
* rotational Raman line/species treatment covered by that response;
* temperature-dependent effective cross section;
* molecular extinction and overlap semantics;
* propagated uncertainty from temperature and spectral-response knowledge.

Until these are established, 530-nm SNR is feasibility evidence only.

## Overlap rule

Raman extinction is based on a range derivative. If the Raman overlap function `O_R(r)` varies with range, the derivative of `ln(O_R)` is indistinguishable from an extinction contribution unless explicitly corrected.

Therefore any real-data Raman boundary diagnostic must either:

1. operate only above an experimentally supported complete-overlap altitude for the relevant Raman path; or
2. use an experimentally validated, uncertainty-carrying overlap correction.

A historical generic SPU overlap statement is not automatically a Raman-channel-specific MerionC overlap calibration.

## Boundary-validation use, not self-validation

A future Raman diagnostic may compare independent aerosol-extinction/layer evidence near an elastic Rayleigh-candidate altitude with the elastic assumption `beta_aer(ref)=0`.

It must not:

* tune the Raman processing to reproduce the elastic KFS profile;
* use the elastic candidate score as a hidden prior for Raman aerosol absence;
* infer aerosol backscatter from Raman extinction by silently assuming a lidar ratio;
* convert 387/530 channel presence or SNR into a cloud/molecular-purity flag;
* use historical filter values as current MerionC values without traceable evidence.

## Controlled synthetic gate before real retrieval

Once current receiver metadata is available, the first executable Raman gate should use analytical/synthetic truth, not `20250629sant` tuning.

Minimum synthetic families:

* pure molecular atmosphere;
* broad aerosol layer terminating below the candidate boundary;
* weak residual aerosol at the candidate boundary;
* localized layer crossing the candidate region;
* aerosol Ångström sensitivity for the 355/387 path;
* temperature/spectral-response sensitivity for the 532/530 path;
* overlap-transition contamination;
* noise plus declared vertical derivative/smoothing resolution.

Success should be assessed against known extinction truth and known boundary contamination, with effective vertical resolution reported separately. Thresholds must not be chosen to reach a desired altitude.

## Current SPU priority

Given the present evidence hierarchy:

1. **387/355** is the first candidate for a quantitative synthetic-to-real Raman boundary experiment once current 387-nm spectral/overlap metadata is traceable.
2. **530/532** remains valuable but requires explicit rotational-Raman temperature/filter physics before quantitative use.
3. `20250629sant` remains the preferred first real feasibility case because corrected 387/530 Level-1 signals are available with useful high-altitude SNR.

No productive method-v5 change is authorized by this document.
